# 全站弹窗界面统一设计

## 目标

将项目中 Element Plus 弹窗、抽屉和手写终端弹窗统一为专业运维控制台风格，解决标题栏、表单布局、按钮层级、滚动区域、遮罩交互和窄屏适配不一致的问题。

## 视觉方向

- 白色弹窗容器，8px 圆角，细蓝灰边框，克制阴影。
- 遮罩使用半透明深灰和轻微模糊，突出当前任务但保留背景上下文。
- 主色使用稳定的运维蓝，不使用蓝绿渐变作为主要确认按钮背景。
- 标题使用深蓝色，辅助说明使用低对比度蓝灰色，错误提示固定在字段下方。
- 关闭按钮统一为 32px 方形图标按钮，支持悬停、按下和键盘焦点状态。
- 普通弹窗宽度控制在 560px 至 680px，复杂弹窗使用 `min(920px, calc(100vw - 32px))`。

## 统一结构

所有弹窗按以下结构组织：

```text
overlay
  popup-shell
    popup-header
      title-group
      close-button
    popup-body
      page-specific content
    popup-footer
      secondary action
      primary action
```

Element Plus 弹窗通过统一样式层接入该结构；手写弹窗补齐等价的结构类名。弹窗内容超出高度时只滚动 `popup-body`，标题栏和底部操作区保持可见。

## 弹窗分类

### 表单弹窗

适用于新增/编辑主机、账号、用户、角色、安全巡检、文件创建和文件属性。

- 桌面端优先使用两列字段布局。
- 窄屏自动切换为单列布局。
- 字段标签、必填标记、输入框高度和错误提示统一。
- 底部操作区固定在内容区下方，取消为次级按钮，保存/确认使用主按钮。

### 选择和管理弹窗

适用于快捷命令、批量执行目标、导入导出。

- 复杂弹窗使用左侧筛选栏和右侧内容区。
- 搜索、数量和主要操作在内容区顶部形成一行工具栏。
- 列表内部独立滚动，禁止弹窗整体出现无意义的横向滚动。
- 导入导出使用清晰的选择卡片、字段分组和格式分段控制。

### 详情抽屉

适用于应用详情、任务进度和安全巡检详情。

- 顶部固定标题和状态信息。
- 内容使用分组区块，不使用连续无层级的长文本堆叠。
- 底部只保留当前上下文需要的操作。

### 终端文件弹窗

适用于删除、创建、属性、上传和下载。

- 保留终端工具的紧凑密度。
- 使用同一套标题栏、按钮、输入框、错误提示和滚动规则。
- 删除类操作使用明确的危险色和动作文案。

## 交互规则

- 点击遮罩空白区域不会关闭弹窗。
- 关闭按钮和取消按钮都明确可见。
- 保存、删除、上传等异步操作期间禁止误关闭。
- Escape 行为遵循现有页面语义；异步操作期间禁止 Escape 关闭。
- 所有关闭动作必须通过现有页面事件或状态管理完成，不改变业务 API。
- 键盘焦点必须可见，首个可编辑字段在不影响现有行为的前提下自动聚焦。

## 覆盖范围

第一阶段统一以下页面和组件：

- 主机新增/编辑、移动、导入、导出和快捷命令。
- 账号、用户、角色和安全巡检弹窗/抽屉。
- 应用市场详情、任务进度和执行预览。
- 批量执行目标选择和执行详情。
- 终端文件创建、删除、属性、上传和下载。
- App 壳层二维码、其他页面中发现的 Element Plus 弹窗与抽屉。

## 验证标准

- 所有 `el-dialog` 和 `el-drawer` 显式禁止遮罩点击关闭。
- 自定义弹窗不使用 `@click.self` 关闭。
- 关键弹窗具备标题、关闭动作、底部操作区和独立滚动内容区。
- 桌面端无标题、按钮、字段或列表重叠。
- 窄屏下弹窗不超出视口，表单降为单列，按钮可点击。
- 运行弹窗结构测试、全量测试和 `npm run build`。
- 启动 Vite 并检查主机编辑、快捷命令、导入导出至少三个场景。
